# Parallel Lanes File Ownership Contract

| Lane           | Role                                        | Owned Directories & Files                                                                                                                                                                                                                                                           | Forbidden Files                                      |
| :------------- | :------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------- |
| **p0**         | Structural De-coupling & Engine Slots       | `src/components/configurator/panels/*`, `src/components/configurator/ConfiguratorShell.tsx`, `src/components/modal/*`, `src/app/layout.tsx`, `src/components/shell/Header.tsx`, `src/engine/buildState.ts`, `src/engine/stages/slots/*`, `docs/lanes/*`, `tests/buildState.test.ts` | Existing domain files, tokens, story, content tables |
| **next**       | Next.js Architecture & Optimization         | `next.config.ts`, app routing, bundle optimizations, fonts/metadata                                                                                                                                                                                                                 | Configurator domain logic, 3D engine stages          |
| **prod**       | Production Hardening & CI/CD                | Deployment configs, environment guards, production telemetry                                                                                                                                                                                                                        | Component internals, 3D models                       |
| **combine**    | Full Force Combine Department Interactivity | `src/components/configurator/panels/CombinePanel.tsx`                                                                                                                                                                                                                               | SoloPanel, SquadPanel, LeadModal, engine core        |
| **modal**      | Lead Modal Forms & Integration              | `src/components/modal/LeadModal.tsx` form logic, submission handling, validation                                                                                                                                                                                                    | ConfiguratorShell, Engine stages                     |
| **enc**        | Encounter Stages 3D Integration             | `src/engine/stages/enc/*`, `src/engine/stages/slots/enc.ts`                                                                                                                                                                                                                         | Raid models, Modal, Configurator domain              |
| **raid**       | Raid Stages 3D Integration                  | `src/engine/stages/raid/*`, `src/engine/stages/slots/raid.ts`                                                                                                                                                                                                                       | Encounter models, Modal, Configurator domain         |
| **overlay**    | 3D Overlay Visuals                          | `src/engine/overlay/*`, `src/engine/stages/slots/overlay.ts`                                                                                                                                                                                                                        | Stage logic, configurator panels                     |
| **integrator** | Cross-lane Integration & Release Merge      | Lane rebases, final verification suite, merge conflict resolution                                                                                                                                                                                                                   | Independent feature authorship                       |

## Isolation Guarantees

1. Each feature lane owns disjoint files.
2. Cross-lane communication occurs exclusively through contracts established in `p0`:
   - Lead modal: `useLeadModal()` from `@/components/modal`.
   - Engine build state: `BuildState` and `setBuildState` from `@/engine/buildState`.
   - Stage slots: `registerEncStage`, `registerRaidStage`, `registerOverlay` from `@/engine/stages/slots`.
